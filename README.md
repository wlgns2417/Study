# Speak English V3

V3는 타이핑 퀴즈가 아니라 **회화 표현 학습** 중심입니다.

- 왼쪽: 영어 표현
- 오른쪽: 뜻 / 뉘앙스 / 실제 예문 / 비슷한 표현
- 이전 / 다음 / 랜덤
- 즐겨찾기
- 다시 보기
- 암기 완료
- 검색 / 카테고리 / 난이도 필터
- 회화 빈도 표시
- 학습 기록 저장

기본 내장 표현: 151개

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```
